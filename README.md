## 关于本仓库

本仓库用于记录个人学习**机器人相关算法与技术**的过程。

学习方式包括观看 **MIT、斯坦福大学的公开课程**，阅读论文和书籍，手写推导公式，下载并运行学习代码，以及深入分析知识点；最后**借助 AI 辅助梳理与整理**，并由个人进行审核、修改，形成学习笔记。

这些笔记仅用于记录学习过程，方便后续复习与回顾，减少重复查阅资料、理解知识点和推导公式所花费的时间。
